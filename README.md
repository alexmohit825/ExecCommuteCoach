# [Vocalis] Executive Commute Articulation Coach
## Project Brief & Architecture Specification

### 1. Vision & Core Value
Vocalis is an acoustic-first, 100% eyes-free verbal sparring coach engineered for automobile commutes, walking, and high-intensity spontaneous articulation conditioning.

### 2. Tech Stack & Platform
* **Platform:** Native iOS Application (iPhone) + CarPlay Scene.
* **Framework:** Swift 6 / SwiftUI / AVFoundation / Speech.
* **Audio Pipeline:** Hardware AVAudioEngine tap + on-device SFSpeechRecognizer + Siri App Intents.
* **Deployment:** GitHub Actions CI/CD to Apple TestFlight.

### 3. Key Modules
* **Hardware Acoustic Telemetry:** Real-time pitch contour, upspeak inflection, and filler phoneme detection.
* **High-Yield Sparring Arenas:** PREP (Executive Defense), STAR (Behavioral Mastery), Table Topics (Impromptu), and Tactical Empathy.
* **Dynamic Friction Mode:** Mid-response executive pushback simulator.
